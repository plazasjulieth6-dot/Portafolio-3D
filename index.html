Propiedades

Clic en un texto para seleccionarlo. Arrastra los elementos con borde para moverlos.

Si pegas un enlace de Sketchfab, el proyecto se abre con el visor de Sketchfab (carga rápido aunque el modelo sea pesado, también en celular) y no usa el visor propio.

Para ver el FBX con color: sube el .fbx y, en el campo de texturas, todas las imágenes (Ctrl/Shift para varias). Si el FBX ya trae las texturas embebidas no hace falta subirlas. Un .GLB ya incluye sus texturas: súbelo solo y se verá con color (en Blender: Archivo → Exportar → glTF 2.0 → formato «glTF Binario (.glb)»).

El video aparece en el apartado «Presentación del proyecto», debajo de la imagen y la descripción. Si subes un archivo y también pegas un enlace de YouTube, se muestra el archivo. Ojo: el video de YouTube solo se reproduce dentro de la página cuando ya está publicada en internet; para verlo reproducirse aquí, en tu computador, sube el archivo MP4. Si no subes imagen principal, se usa la miniatura del enlace de YouTube.
